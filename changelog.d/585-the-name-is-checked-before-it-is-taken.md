**The name has a written bar, and two proposed names were measured against it.** The tool was called
`quay`, which is Red Hat's container registry, and nobody found that out until after the name was in
346 files. Issue 517 fixed the name. It did not fix the thing that let the name through.

`docs/NAME.md` now says what a name has to clear: no larger product in this field carries it, and a
person can say it, spell it and find it. It names the registries to check and it records the check
that `krewe` passed, including the one cost `krewe` carries, that it sounds like "crew".

`fabric` and `blueprint` were both measured against that bar and both were refused. `fabric` is
carried by four products above fifteen thousand stars, and one of them is a Go command line tool that
runs prompts, which is this field exactly. `blueprint` is a noun inside Flask, inside Unreal Engine
and inside the Amazon Web Services Terraform modules, so a search for it lands anywhere but here.

The file also says what nobody checked. No name here has been searched against a live trademark
register, because neither register answered from a sandbox. That is written down as unknown rather
than left to read as clear.
