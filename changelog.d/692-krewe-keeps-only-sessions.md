**Krewe keeps only sessions.** Jobs, flows and roles are removed, with everything built on them:
executions, gates, the controller, messaging and channels, the room, the briefing page, the headless
browser, the forge client, publishing, machine capacity and `docs/`. Four stages and a controller
produced work nobody could use. A session with its hooks and its skills produces work, so that is
what the system is now.

The console tree is three levels: workspaces, then projects, then sessions. A session's tasks are one
key further along, on `t`. Health probes the store, because there is no event log left to probe.
Every removed command word refuses by name and says what to type instead.

A migration drops twenty tables and the session role column. There is no way back from it.
